# Adversarial Markov Games

A Reinforcement Learning based framework for adaptively optimizing black-box, decision-based attacks and stateful defenses against each 
other through the competitive, zero-sum game they form.

## Requirements

- Python 3.7.7
- OpenAI-Gym 0.22.0
- Stable-Baselines-3 0.10.0

## Use

We provide the source code we experimented with as is. The whole range of evaluation scenarios are in the parent directory, while the different RL environments are defined in the envs folder. Note that this repository is work in progress as restructuring and improvements are being actively made.
